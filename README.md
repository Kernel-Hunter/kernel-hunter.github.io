# kernel-hunter.github.io

The source for [kernel-hunter.github.io](https://kernel-hunter.github.io/), a one-page list of the free, open source projects I work on, with links to each one and to the Kernel Hunter accounts.

It is plain HTML and CSS with no build step, no JavaScript and no tracking. GitHub Pages serves it straight from the `main` branch.

To preview it locally, open `index.html` in a browser or run `python3 -m http.server` in this folder.

Project icons belong to their own repositories: [Boost](https://github.com/Kernel-Hunter/boost), [Mudroom](https://github.com/Kernel-Hunter/mudroom), [Narrata](https://github.com/Kernel-Hunter/narrata) and [Kandle](https://github.com/Kernel-Hunter/kandle).
